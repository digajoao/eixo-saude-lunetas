## Como publicar no GitHub Pages

### Passo a passo

1. Entre no GitHub e crie um repositório novo (ex.: `lunetas-eixo-saude-2026`). Pode ser público ou privado. Para publicação, precisa ser público (ou ter plano paid para Pages privado).
2. Clique em **Add file > Upload files** e suba o `index.html` e este `README.md`.
3. Confirme o commit.
4. Vá em **Settings > Pages**.
5. Em **Source**, escolha **Deploy from a branch**.
6. Em **Branch**, escolha `main` e pasta `/ (root)`. Clique em **Save**.
7. Aguarde ~1 minuto. A página fica disponível em:
   ```
   https://<seu-usuario>.github.io/lunetas-eixo-saude-2026/
   ```

### Para atualizar o relatório

Edite o `index.html` localmente, suba a nova versão pelo mesmo caminho de upload, e o site é atualizado automaticamente.

## Dados pessoais

Este relatório não traz:

- Nomes de usuários do Instagram que comentaram ou interagiram
- Contatos pessoais de fornecedores (telefone, e-mail)
- Dados bancários ou CNPJs
- Transcrições das entrevistadas do videocast

Para compartilhar materiais brutos do especial (áudio, vídeo, transcrições), usar canais restritos com autorização das entrevistadas.
